## How the placeholders work

Every slot is a `<Media>` component from `/snippets/media.mdx`:

```mdx
<Media>The Items card with four rows, one expanded</Media>
<Media kind="Video">Following a preset link in a private window, 20 seconds</Media>
```

It renders a dashed box with the caption inside. To find every slot:

```bash
grep -rn '<Media' cartpresets/
```

To replace one, swap the component for a real frame:

```mdx
<Frame caption="The Items card with four rows, one expanded">
  <img src="/images/cartpresets/items-card.png" alt="The Items card" />
</Frame>
```

When every slot is filled, delete `/snippets/media.mdx` and the import lines.

## Suggested conventions

- Capture at 1440px wide, 2x for retina.
- Use the same demo store throughout — consistent product names read as one product, not several.
- Crop to the card being discussed rather than the whole page, except where the caption says otherwise.
- Put files in `/images/cartpresets/` so they stay separate from Unwan's.
