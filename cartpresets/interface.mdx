CartPresets for WooCommerce adds a top-level **Cart Presets** menu in wp-admin, plus one entry under **Products** and, on Pro, one report under **Analytics**. If you would rather it took one line of the menu, **Settings → Admin menu → One entry under Products** removes the top-level menu and leaves only **Products → Cart Presets**; Add New and Settings are then reached from the listing.

| Menu entry | What it is |
| --- | --- |
| Cart Presets → All Presets | The listing |
| Cart Presets → Add New Preset | The editor, empty |
| Cart Presets → Settings | Store-wide settings, and on Pro the licence |
| Cart Presets → Upgrade to Pro | Free version only — what Pro adds |
| Products → Cart Presets | The same listing, where you would look for it |
| Analytics → Cart Presets<Pro /> | The Presets report |

## The listing

<Media>The All Presets screen, showing the search, filter, status tabs and listing settings</Media>

### Finding a preset

**Search** matches preset names and the names of products inside them — so searching "hoodie" finds every preset containing a hoodie, not just presets called hoodie.

**Status tabs** across the top count and filter by derived status. The count beside each is live.

**Filter** opens a query builder. Each row is a field, an operator and a value, and rows combine with AND:

| Field | Type | Operators |
| --- | --- | --- |
| Status | choice | is, is not |
| Product name | text | equals, contains, does not contain, starts with |
| Coupon | text | equals, contains, does not contain, starts with |
| Price | number | equals, greater than, less than |
| Order revenue | number | equals, greater than, less than |
| Orders | number | equals, greater than, less than |
| Stock problem | yes/no | is |

<Tip>
  **Order revenue** means money, not a count of orders. The count is the separate **Orders** field.
</Tip>

**Listing settings** sets the sort (date, name, status, items, price or orders, ascending or descending), how many presets a page shows, and which columns are visible. On a narrow screen the table stacks each row into a block.

### The columns

| Column | Shows |
| --- | --- |
| Preset | Name, overlapping product chips, and the item and unit count |
| Status | Active, Scheduled, Expired, Sold out or Inactive — derived, not stored |
| Price | What a customer pays, computed from live product prices |
| Revenue<Pro /> | Net revenue recorded against this preset |
| Date | Publish date and state |
| Link | The preset URL, with a copy button |
| Items | How many items and units (hidden by default) |
| Description | The internal description (hidden by default) |
| Actions | The row menu; Edit, Duplicate and Delete also sit under the preset's name |

On the free version the Revenue column is still drawn, with a crown in place of the figure. Clicking it explains what Pro would show there.

### The row menu

| Action | Notes |
| --- | --- |
| Edit preset | Opens the editor |
| Copy link | The preset URL, to the clipboard |
| Duplicate | Copies everything; the copy is inactive until you turn it on |
| Clear end date<Pro /> | Only shown when there is one. Puts an ended preset back on sale |
| Export as JSON<Pro /> | Downloads this one preset |
| Activate / Deactivate | Flips the status |
| Delete preset | Asks first, and cannot be undone |

### Bulk actions

Tick the checkbox on any row — or **Select all presets on this page** — and choose from **Bulk actions**: Activate, Deactivate, Duplicate or Delete. Bulk delete asks for confirmation and names how many rows it will remove.

## The editor

<Media>The full preset editor, main column and sidebar visible</Media>

The editor is one page, a main column and a sidebar that both update as you type.

### Main column

| Card | What it holds |
| --- | --- |
| Preset details | Name, slug, publish date<Pro />, internal description |
| Items | Every item in the preset, each expandable |
| Cart behaviour | The same questions Settings asks, for this preset: the cart this link finds, where the customer lands afterwards, and an automatic coupon<Pro /> |
| Limits and schedule<Pro /> | End date, purchase limits, and what happens when it ends |
| Link restrictions<Pro /> | Sign-in requirement, roles, rejection message |

The editor's cards follow the Settings screen's own order and wording, so a question you have answered store-wide reads the same when you answer it again for one preset.

### Sidebar

**Pricing summary** recalculates on every keystroke: items, regular value, item discounts, average per unit, and the preset total. Every figure is what the customer's cart will hold.

**Health checks** asks a series of questions of the draft. A `fail` blocks the save; a `warn` does not. Clicking a check scrolls to the control it is about and highlights it. See [Health checks](/cartpresets/building/health-checks).

**Preset link** shows the live URL with a copy button, and says so if the preset has not been saved yet.

### The save bar

Pinned to the bottom, and it always says which of three states you are in: **All changes saved**, **Unsaved changes**, or the number of blocking problems. **Discard** reverts to the last save.

<Note>
  Leaving with unsaved changes asks first — whether you click a link inside the panel or one in wp-admin's own sidebar.
</Note>

## Settings

<Media>The Settings screen, carrier product card and cart behaviour section</Media>

Six sections share one save bar, and on Pro the Licence card sits above them:

| Section | Covers |
| --- | --- |
| Licence<Pro /> | Licence key, status, updates — acts immediately, outside the save bar |
| Carrier product | The hidden product custom items ride on |
| Cart behaviour | What a link does to the cart it finds, what happens when an item cannot be added, which order statuses consume a purchase-limit slot, and where customers land. Each destination carries an explanation, and a custom one takes a URL |
| Cart notices and labels | All nineteen customer-facing strings |
| Links and fallbacks | URL parameter, pretty permalink base, the fallback link, UTM handling, and what happens when a preset reaches its limit or end date<Pro /> |
| Admin menu | Its own Cart Presets menu, or one entry under Products |
| Data control | The three uninstall opt-ins, and exporting and importing presets<Pro /> |

The sidebar carries a **System status** card — plugin version, WordPress, WooCommerce, PHP, permalink structure, preset base, and tier — with a **Copy system report** button. That report is read from your own install and sent nowhere; it is there so you can paste it into a support thread.

Full detail: [Settings reference](/cartpresets/settings/reference).

## Where a preset shows up elsewhere

- **The cart and checkout** — each line carries a **Part of preset** label with the preset name. Both labels are editable.
- **The order** — the same label, plus hidden meta a developer can read. See [Order line item meta](/cartpresets/developers/order-meta).
- **Order emails** — the order label, with the preset name as it was when the order was placed.
