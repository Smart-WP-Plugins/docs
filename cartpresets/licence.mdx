## Activating

Go to **Cart Presets → Settings**. The **Licence** card is the first card on the screen. Paste the key from your purchase email into **Licence key** and click **Activate**.

<Media>The Licence card at the top of Settings, showing the masked key, plan, sites, renewal date, last checked, and the Sync now and Deactivate on this site buttons</Media>

Once it's active, the card shows the key with all but its last four characters hidden, and:

| Row | Shows |
| --- | --- |
| **Plan** | Your plan |
| **Sites** | How many of your activations are in use, like "2 of 5 in use" |
| **Renews** | When the licence renews, or **Never** for a lifetime licence |
| **Last checked** | When the licence was last checked with the licensing service |

| Button | Does |
| --- | --- |
| **Sync now** | Checks with the licensing service now, instead of waiting for the next check |
| **Deactivate on this site** | Releases this site's activation so you can use it elsewhere. It asks first |
| **Manage account** | Opens your account with the licensing service, in a new tab |

The card's buttons act straight away. They're not part of the Settings save bar, so there's nothing to save afterwards, and **Discard** won't undo them.

### Who can change it

Only an administrator can activate, sync or deactivate the licence. The licence decides whether the site gets updates, and WordPress keeps plugin updates for administrators too.

Anyone else who can open Settings, such as a Shop Manager, sees the card read-only: the status and the facts, with no key field and no buttons, and a note saying *Only an administrator can change the licence*. They don't see the licence notice either, because its one link is to something they can't do.

### A key with no account yet

A key you bought is already attached to your account. A key that was issued by hand might not be. Activating one of those needs a name and email to create the account, so the card asks first.

A **Create an account for this key?** dialog shows the **Name** and **Email** that will be sent: the ones on your WordPress user. Nothing is sent until you click **Create account and activate**. **Cancel** sends nothing. You can change both details later in your account.

<Tip>
  Deactivate before you move a site or tear down a staging install. That frees the activation instead of leaving it held by a site that no longer exists.
</Tip>

## What a licence buys

**Updates and support.** Not the right to keep running what you already have.

Plugins differ on this, so it's worth spelling out:

<Note>
  **When your licence expires, the plugin carries on working exactly as installed.** Nothing switches off, nothing is deleted, and no setting stops applying. You just stop getting new versions until you renew.
</Note>

Which version is on disk decides the tier, never licence state. An expired licence leaves every Pro file exactly where it was, so every Pro feature keeps working.

## What is sent, and when

Your licence key and site URL go to the licensing service: to activate, to check in periodically, and to look for updates. Your name and email go only when you confirm them for [a key with no account yet](#a-key-with-no-account-yet).

It runs from **wp-admin and cron only**. Your storefront never reaches it, so a customer browsing your shop never triggers a licence check.

The key is never written to a log, never returned in an API response, and never shown in a notice. An update check sends it in a request header, not in the address, because addresses end up in server logs.

## Updates

With an active licence, Pro updates show up on your Plugins screen like any other plugin. Update in place. Your presets, items and settings are database rows, and the swap doesn't touch them.

WordPress checks for updates on its own schedule: roughly twice a day, and more often while you're sitting on the Updates screen.

## The licence notice

Without an active licence, WordPress shows a dismissible warning across wp-admin, including the CartPresets list and editor. It's a standard WordPress admin notice, and it has a **Manage licence** link that opens Settings at the Licence card.

You won't see it on Settings itself, where the card already tells you the same thing.

Dismissing it is per user, and it stays dismissed for that licence state. If the state changes, say an expiry or a detached site, the notice comes back once, because now it's telling you something new. It goes away by itself once the licence is active.

Each version says what stopped and what didn't, because the honest answer to *my licence lapsed* is that almost nothing changed.

## Licence states

The card's badge shows which state you're in.

| Badge | Means | The card shows | Updates |
| --- | --- | --- | --- |
| **Active** | Everything is fine | The key, the facts, **Sync now** and **Deactivate on this site** | Yes |
| **Expired** | The term ended | **Your licence has expired**, with a **Renew licence** button, above the same facts | No, until renewed |
| **Cancelled** | This site is no longer attached to a licence | **This licence was cancelled**, with **Deactivate on this site** so you can activate a current key | No |
| **Not activated** | Never activated on this site | The **Licence key** field and **Activate** | No |

In all four, every Pro feature keeps working.

## Moving a site

Staging and production count as separate activations. If you've run out:

<Steps>
  <Step title="Deactivate on the site you're leaving">
    **Cart Presets → Settings**, then **Deactivate on this site** on the Licence card.
  </Step>
  <Step title="Activate on the new one">
    Paste the same key.
  </Step>
</Steps>

If the old site is already gone and still holding an activation, contact support. We can release it from our side.

## For developers

`cartpresets_update_manifest_url` changes where a site looks for its release manifest. Point it elsewhere to run a pre-release channel, or return an empty string to switch automatic updates off for that site entirely.

The licence is checked **before** the manifest is fetched, so the filter changes which release a licensed site is offered. It doesn't bypass licensing. See the [hooks reference](/cartpresets/developers/hooks-reference#updates-pro-only).
