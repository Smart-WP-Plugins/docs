Admin Powerups for WooCommerce bundles small, practical admin improvements into one plugin. Each improvement is a power-up. Every power-up is off until you switch it on under **WooCommerce → Powerups**, so nothing on your store changes until you choose it.

Some power-ups have settings, some add a tool tab, and some just work once they're on.

## The power-ups

### Orders

| Power-up | What it does | Shows in |
|---|---|---|
| [Advanced order search](/admin-powerups/advanced-order-search) | Search orders by customer, phone, SKU, total, coupon, notes and more | Orders list |
| [Autocomplete orders](/admin-powerups/autocomplete-orders) | Mark orders completed automatically when your rules match | Order status after payment |
| [Save order address to customer](/admin-powerups/save-order-address) | Copy an order's address to the customer's profile | Order page |
| [Payment link helper](/admin-powerups/payment-link) | Copy, open or email the payment link for unpaid orders | Order page, Customer pages box |
| [Thank-you page preview](/admin-powerups/thankyou-preview) | Open an order's thank-you page without firing tracking scripts | Order page, Customer pages box |
| [Order meta inspector](/admin-powerups/order-meta) | See every piece of data saved on an order and its items | Order page |

| [Customer table columns](/admin-powerups/customer-table-columns) | Add customer details, orders and spend to the Users list | Users list |

| [Duplicate customer finder](/admin-powerups/duplicate-customers) | Find accounts that look like the same person | Find duplicates tab |

## How it works

- **Opt-in.** A power-up that's off adds nothing to your store.
- **Settings work while off.** You can set a power-up up first and switch it on when you're ready.
- **Your data stays on your site.** The plugin has no tracking.
- **You can remove what it stores.** Each power-up has a Data section that lists what it saves and lets you delete it. See [Data and uninstall](/admin-powerups/data-and-uninstall).
