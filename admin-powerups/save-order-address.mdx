Save order address to customer copies an order's billing or shipping address to the customer's profile, with a button or automatically.

**Shows in:** Order page

## Turn it on

Go to **WooCommerce → Powerups** and switch on **Save order address to customer**.

## Save an address by hand

<Steps>
  <Step title="Save the order first">
    Edits you haven't saved aren't copied. If you changed the address, click **Update** on the order first.
  </Step>
  <Step title="Click the button">
    Under the billing or shipping address, click **Save to customer profile**.
  </Step>
</Steps>

<Frame caption="The Save to customer profile button under an order's billing address">
  ![The Save to customer profile button under an order's billing address](/images/admin-powerups/save-order-address-1.png)
</Frame>

The button only shows for orders linked to a customer account, and only for staff who can edit that customer's account. Each save adds an order note.

<Note>
On multisite, only super admins can usually edit network users, so site admins and shop managers don't get the button.
</Note>

## Settings

| Setting | Default | What it does |
|---|---|---|
| **Show save buttons on orders** | On | Adds a button under each address. |
| **Also save automatically when an order is** | Never | Save the address when an order reaches this status. Useful for orders you create for customers. |
| **Addresses to save** | Billing, Shipping | Which addresses the automatic save copies. |
| **Skip empty fields** | Off | On: keeps what the profile already has instead of clearing it. Off: an exact copy. |

The automatic save never updates staff accounts (order editors, store managers and admins). On multisite, that includes people who are staff on any other site in the network. Other accounts are updated when:

- the person changing the status may edit that customer (shoppers may always edit their own account), or can edit orders and the account's only role on this site is Customer;
- nobody is logged in, as with payment webhooks and scheduled jobs, and the account's only role on this site is Customer.

## Data

| Item | What it is |
|---|---|
| **Settings** | This power-up's saved settings. |
| **Addresses saved to customer profiles** | Stays. They are the customers' own addresses now. |

## Messages

| Message | Meaning |
|---|---|
| Update the order first, then save. | The order has unsaved changes. |
| This order has no customer account. | It's a guest order. |
| You are not allowed to edit this customer. | You don't have permission to edit that user. |
